PlanQuest 使用说明（v2.9.7）
================================
这是随包的纯文本速查，只讲「怎么操作」。
想看得更清楚，打开同目录这三份：

  PlanQuest-快速上手.html    3 分钟，装上到打出第一次卡
  PlanQuest-完整手册.html    每个功能怎么用、数值怎么算、边界在哪
  PlanQuest-更新日志.html    从 v1.1 到 v2.9.4，每个版本改了什么

【使用方法】
1. 把整个 PlanQuest-win64 文件夹复制到任意位置（D 盘、U 盘都行）。
2. 双击 PlanQuest.exe 即可运行。
   · 无需安装 Node、Python 或任何运行环境。
   · 支持 Windows 10 / 11（64 位）。
3. 关闭窗口 = 最小化到系统托盘，提醒功能继续在后台运行。
   想彻底退出：右键托盘图标 → 退出。

【功能一览】
· 计划与提醒：创建每日/每周重复计划，到点弹置顶提醒窗，打卡得积分。
· 积分：新装或重置数据后自带 100 积分；打卡、连续打卡、全勤、番茄专注继续累加。
· 分享海报（邀请函，不是成绩单）：成就页 / 设置页可生成。
   - 只写「做了什么」：连续专注天数 / 本周帮过几个战友 / 完成几个挑战 /
     最长一次坐了多久 / 今天在做的事。五项默认全关，逐项勾选才画进图；
     计划名可打码只留首字。
   - 不写「多牛」：信誉等级、具体分数、排名、可借额度一律不出现，
     这四类数据根本不会传进绘制代码。
   - 底部是「扫码加入我的自习室」+ 二维码，码里带邀请码与过期时间，
     24 小时有效；过期后再扫会直接提示「邀请已过期」。
   - 署名可以单独填别名（存本机、不跟账号昵称绑定）。
   - 安卓 App 可直接分享到微信好友 / 朋友圈；电脑版复制邀请链接并保存海报图。
· 今日三件事：每天最重要的 3 件小事。
· 番茄钟：专注 25 分钟 + 休息 5 分钟，专注时长计入统计。
· 自习房（局域网）：同一 WiFi 下多人共学。
   - 房主点「创建房间」得到 4 位房间码；同学输入「IP:房间码」加入。
   - 成员互相可见学习状态、专注分钟数，可发表情给全房间加油。
   - 房间聊天：房间内可打字交流（回车发送），新加入能看到最近聊天记录。
   - 发言检测 · 自动禁言：命中违规词（广告 / 加微信 / 代写代考 / 链接等）
     禁言 5 分钟；10 秒内发超过 5 条禁言 1 分钟；连续发 3 条相同内容
     禁言 2 分钟。被禁言会显示横幅和剩余时间，房主也可手动禁言 / 解禁。
   - 房主自己的违规消息会被直接拦截（房主不会被禁言）。
· 娱乐房：用积分兑换时长的放松房间。
   - 开房消耗积分：每 10 分钟 15 分，最长 120 分钟（2 小时），到点自动结束。
   - 加入娱乐房也要消耗入场积分：按剩余时长每 30 分钟 15 分
     （最低 15、最高 60 分），加入前会弹窗确认；积分不足无法加入。
   - 娱乐房期间灰名单应用放行（黑名单仍然强制关闭）；
     房主退出或时间到，立即恢复限制。
   - 拉人：点「拉人」可看到同一 WiFi 下开着本应用的同学，
     点「邀请」对方会收到弹窗，确认后直接加入（无需手动输 IP）。
· 摄像头测心跳：自习房内开启摄像头，通过面部微色差估算心率（BPM），
  仅作专注状态参考，画面与数据全程不离开本机。
· 守护 · 强制模式：
   - 创建守护账户（用户名 + 密码），密码仅以哈希保存在本机。
   - 黑名单应用：开启即强制关闭，每次提醒弹窗 5 次未打卡会扣积分。
   - 灰名单应用：非计划时间开启即强制关闭。
   - 白名单应用：随时可用。
   - 修改名单 / 关闭强制模式需输入守护账户密码。
   - 账户名与密码哈希可随自习房同步到局域网内其他成员（不传明文）。
   - 修改/删除计划需输入密码，并扣除少量积分。
   - 整软查杀：按程序名结束该软件的全部进程与子进程，
     每 2.5 秒扫描一次，被关掉再打开会立刻再次被关闭。
   - 自动提权：开启强制模式后，应用启动时会自动请求管理员权限
     （首次弹 UAC 点「是」授权一次；之后通过最高权限计划任务
     静默提权，不再弹窗），确保能关闭以管理员运行的软件。
· 积分商城（设置页）：
   - 打卡、专注攒下的积分可兑换奖励。
   - 预置 4 个默认商品，可自定义添加（名称 / 图标 / 所需积分）。
   - 兑换「娱乐券」类商品（如游戏时间 30 分钟）后，倒计时内
     灰名单应用放行；黑名单应用仍然强制关闭。
   - 兑换记录自动保存，积分不足时无法兑换。
· 目标系统（目标页）：
   - 设定目标（如「3 个月减重 5 公斤」「一年读完 24 本书」），
     拆解为每周/每月里程碑，环形进度条实时显示完成百分比。
· 契约模式：
   - 发起「自律挑战」，填写监督人与每日罚金；每天打卡，
     漏打卡的日子会列出「需向监督人发红包 ¥X」清单，
     转账后点「我已转账」销账（应用只记录，不代转账）。
· 打卡体验：
   - 补卡：每月限 3 次，需填写理由，补卡得一半积分。
   - 连续提醒：未打卡每 2 小时再次弹窗，直到完成或当天忽略。
   - 每日小结：记录今日状态与感受。
   - 每周复盘：自动汇总本周打卡率，可记录下周改进项。
· 专注模式（环境隔离）：
   - 设置页开启后隐藏桌面全部图标（减少视觉诱惑），
     关闭或退出应用时自动恢复。
· 护眼模式（到点强制休息，设置页）：
   - 节奏三档可选：30 分钟 → 休息 10 分钟 / 45 分钟 → 休息 15 分钟 /
     60 分钟 → 休息 20 分钟（默认 45 / 15）。
   - 到点弹出全屏护眼页，播放内置离线眼保健操视频（约 4 分钟），
     随后强制息屏 10 / 15 / 20 分钟（随所选节奏），期间 Alt+F4 关不掉。
   - 开关、跳过、调整节奏都需要守护密码；改完节奏立即按新节奏重新计时。
· 数据可视化与导出（成就页）：
   - 本月打卡日历热力图（绿=完成，红=未完成）。
   - 近 30 天打卡率折线图。
   - 一键生成可打印/截图分享的月度日历图（浏览器打开）。
   - 导出 Excel 可直接打开的 CSV 打卡明细。
· 成就徽章：
   - 初出茅庐（连续 7 天）、自律达人（连续 30 天）、
     晨型人（累计 14 天完成 8 点前的计划）等彩色徽章收集。
· 成就系统：连续打卡、全勤徽章、7 日热力图。
· 云同步（v1.1 新增，设置页）：
   - 用手机号验证码登录后，打卡记录 / 积分 / 商城 / 目标自动同步云端，
     手机版（APK）、网页版、电脑版共用同一账号数据。
   - 不登录照常使用，数据只存本机；联网时本机改动约 1.5 秒后自动上传。
   - 换电脑 / 重装系统：登录同一手机号即可找回；首次连接若云端和本机
     都有数据会弹窗让你选择保留哪一边。
   - 守护密码、黑白灰名单、开机自启等本机设置不参与同步。

【数据与备份】
所有数据保存在 C:\Users\<用户名>\AppData\Roaming\PlanQuest\data.json，
换电脑时把该文件复制到新电脑同一路径即可迁移全部记录。

【局域网联机注意事项】
首次使用如 Windows 防火墙弹窗，请选择「允许访问」（专用网络），
否则其他设备将无法加入房间。

【开机自启】
设置页开启「开机自动启动」时会先弹一次说明：这一步会在注册表
  HKCU\Software\Microsoft\Windows\CurrentVersion\Run
写入一条当前用户的启动项，只对你自己生效，不需要管理员权限，也不会改别处。
关掉开关就删除这条。绿色安装程序本身不写注册表（它只负责解压）。
绿色版换目录后，应用下次启动会自动把启动项指向新位置，不用手动改。

【安装助手与版本更新】
· 分发两个 exe，按需要选一个：
    1) PlanQuest-安装助手.exe（约 2 MB，纯引导器）：本身不含主程序，向导全中文。
       双击后向导里选「装哪个版本」+ 勾「要不要装 AI」，再去下载源把对应
       版本的绿色 ZIP 原样完整解压到所选目录（保留包内 PlanQuest-win64\），
       解压成功后才在桌面建「PlanQuest」快捷方式，指向真实 exe，图标用软件自带图标。
       下载优先走 GitHub API 资产接口（releases/download 被代理拦时仍能下载），
       失败会自动退回 releases 直链；失败详情写到所选安装目录的 pq-download.log。
       下载或解压失败会明确报错、不留死链；网络不好时它就下不动。
       实际所需磁盘空间：主程序解压后 376.1 MiB，下载临时 ZIP 194.2 MiB，
       两者同时存在时峰值约 570 MiB；安装助手本身约 2 MiB（不含可选 AI 组件）。
       发布的 ZIP 只含程序与资源，没有任何用户数据，始终是初始状态。
    2) PlanQuest-<版本>-setup.exe（单文件，约 161 MB）：内嵌整包，
       双击离线也能装上，版本固定。不提权、只解压、不写注册表。
  两者都不提权、不写注册表、不建开始菜单、不建卸载项、不碰开机自启。
· 设置页「版本更新」不再让你填下载源（源已内置五源冗余，换源见下节「安装源」）。
  点「检查更新」逐个源比对版本，有新版再依次下载，某个源失败自动换下一个，
  全失败才报「哪个源、什么原因」；下到的包按 sha256 校验，落到独立目录，
  不覆盖正在运行的 exe。
· 数据不用迁移：data.json 在 %APPDATA%\PlanQuest\，换任何绿色版自动沿用。
· 可选大模型默认都不下载。安装助手的两个复选框 / 设置页的「下载所选组件」
  勾了才从官网下到「安装文件夹内的 components\ 目录」（绿色版拷走时 AI 一起带走）：
    - Ollama：官网 ollama-windows-amd64.zip（绿色解压即用），
      模型再执行 ollama pull qwen2.5:3b；无独显时 CPU 推理要等几十秒。
    - MeloTTS：官网只有源码，没有 Windows 运行包；本机 Python 3.13
      装不上 torch<2.0，勾了只会得到源码 zip，不代表能运行。

【安装源（换源看这里）】
· 五类源按优先级自动切换，任一成功即可；每个源都应同时放两份字节一致的 ZIP：
    主包 PlanQuest-win64-portable.zip 与备份 PlanQuest-win64-portable-backup.zip。
    安装助手会先试 GitHub API 资产接口（绕过 releases 直链被拦），再试两份 ZIP 的
    直链、备份直链，最后才用你在 assistant-sources.txt 里写的源。
    ① GitHub Releases（内置主源）：https://github.com/supercalifragilisticexpialidociouer/PlanQuest/releases/latest
       专属版本直链形如 https://github.com/supercalifragilisticexpialidociouer/PlanQuest/releases/download/v2.9.11/PlanQuest-win64-portable.zip
       备份直链形如 https://github.com/supercalifragilisticexpialidociouer/PlanQuest/releases/download/v2.9.11/PlanQuest-win64-portable-backup.zip
    ② R2 / 任意直链：https://your-domain.com/planquest/2.9.11/PlanQuest-win64-portable.zip
    ③ pixeldrain：安装助手会把分享链接自动转成 API 直链
       https://pixeldrain.com/u/xxxxx 或简写 pixeldrain:xxxxx
    ④ MediaFire 分享页：直接贴 https://www.mediafire.com/file/xxx/... ，
       或简写 mediafire:https://... ；下载时自动带浏览器标识。
       若页面要求人工验证码，需要你先在浏览器完成验证后再装。
    ⑤ GoFile 分享页：https://gofile.io/d/xxxxx 或简写 gofile:xxxxx；
       安装助手会先读元数据拿直链；带密码的写法 gofile:xxxxx|密码。
· 给「安装助手」换源：在 安装助手.exe 同目录新建一个纯文本 assistant-sources.txt，
  每行一个源（# / ; 开头是注释），例如：
      https://r2.example.com/planquest/releases/latest
      https://pixeldrain.com/u/xxxxxxxx
      gofile:xxxxxxxx
      mediafire:https://www.mediafire.com/file/xxxxxxxx/PlanQuest-win64-portable.zip
  没有这个文件就用内置的 GitHub 主源。想给某个版本指定专属直链，
  在该版本目录约定文件名 PlanQuest-win64-portable.zip，助手按版本自动拼路径。
· 给「应用内更新」换源：五源已编译进程序，一般用不到；确需自建，
  用 ISCC.exe 重编译 tools\PlanQuest-setup.iss / tools\PlanQuest-Assistant.iss，
  改其中 DEFAULT_SOURCE 等常量即可（源码见 tools\）。
· 发版侧：把不带大模型的绿色版 zip 和 setup.exe 传到上面任一/多个源即可；
  用 ISCC.exe 编译 tools\PlanQuest-setup.iss 得到离线安装器、
  编译 tools\PlanQuest-Assistant.iss 得到本节的在线安装助手。
  version.json（node tools/build-manifest.js）仍生成，供 R2 直链源使用。

【AI 盯学（自习房内）】
· 房间里开启摄像头共享后，点「🤖 AI 盯学」开启摸鱼检测：
  每 5 秒用本地 AI 模型分析你的摄像头画面，判断你在「认真学习」还是
  「摸鱼」（睡觉 / 趴桌 / 玩手机 / 发呆）。
· 连续 2 次（约 10 秒）判定摸鱼 → 房间聊天自动广播 + 扣 2 积分
  （允许扣成负分），摄像头画面边框变红警示；认真时边框变绿。
· 模型完全在本地运行，画面不会上传；关闭摄像头即自动结束，
  结束时会汇报本场「认真 / 摸鱼 / 抓包」统计。

【AI 强制开启】
· 闲聊雷达：房间聊天里的每条消息都会被本地模型判断（🐟 闲聊 / 📖 正经事），
  开关已取消，无法关闭；判定为你自己发的闲聊每攒到 3 条，强制扣 2 分（没有扣分开关）。
· AI 盯学：开摄像头共享即自动开始（每 5 秒分析一帧），无法手动关闭；
  关掉摄像头共享或退出房间即自动结束。

【信誉分（与借分共用一套分，0~160）】
· 位置：成就页「信誉分」卡片。三支柱：诚实度 / 联盟贡献 / 成长。
· 诚实度：
  - 翻案经房间同学认可、相似佐证或冷静期复核成立 → +3；
    被房间多数否决、或翻案后 10 分钟又连判 3 条闲聊 → -8。
  - 举报需房内 ≥3 位不同同学同时举报并核实 → 举报者 +4；被核实违规 -2 起；
    7 天内 5 次举报 0 次核实 → 标记恶意举报，-10 且举报权重降为 0。
  - 借分按时还清 +10；逾期 -30、额度腰斩、30 天不能借；
    分数掉到 0 直接进「失信期」24 小时（不能借分、不能翻案）。
· 联盟贡献：别人在房间里点「🙏 感谢」（对方确认才算）→ +2/次（对同一人每天一次、每天最多 3 次）；
  房间连续稳定在线 30 分钟 → +1。
· 成长：当天计划全部完成（全勤）+1；单日专注刷新个人纪录 +2。
· 所有加分都有每日上限，刷不出来；未参与计分的（问卷、房间标签准确性）只做记录。
· 三档特权（成就页信誉卡里能看到自己具备哪档、还差多少分）：
  - L1 基础（≥80）：翻案权重 / 每日翻案次数 / 借分额度（受限 30、普通 50）。
  - L2 社交（≥100）：可以自己开军团（低于 100 分只能加入别人的）；
    能被推选为纪律官 / 仲裁员，参与裁定争议。
  - L3 荣耀（≥120）：军团名册里挂 ✦ 守约者星标。
  - 借分额度按档给：受限 30 / 普通 50 / 良好 80 / 可信 120；
    按时还清翻倍（上限 2.5 倍）、逾期减半，区间 10~200。分掉档额度当场跟着降。
  - 自习房优先匹配、抢先体验两项尚未实现，界面标「规划中」。
  - 信誉分不能买、不能用积分兑换，只能靠打卡 / 守约 / 助人被核实慢慢攒。

【AI 自训练】
· 纠正样本，越用越懂你（文字与画面同一套翻案风控）：
  - 双击聊天里的 🐟/📖 徽章（手机长按 / 右键）→ 必选理由 → 二次确认；
  - AI 盯学抓包后，房间出现「刚才那帧真的是摸鱼吗？」→ 同样选理由后提交。
  - 翻案不是点一下就生效：按信用分（与积分借贷同一套）分四档限额
    （受限 2 / 普通 5 / 良好 10 / 可信 20 次/天），两次间隔 ≥15 秒，
    同一条消息 24 小时只能翻一次；超限锁到次日。
  - 只有「良好」以上且行为一致才直接采纳；其余进候选池（气泡挂「⏳ 待确认」，
    原判定不变）。候选池要靠房间其他同学「认可」（≥1 票、且多于反对）转正，
    或者等 30 分钟冷静期后二次确认、另一条相似翻案佐证。
  - 面对投毒：翻成"正经事"但近期 80% 判定都是闲聊 → 权重×0.3 强制进候选池；
    广告/纯表情/刷屏乱码在本地直接拦下；翻案后 10 分钟又连判 3 条闲聊 →
    自动回滚 + 信用 -5，一天被回滚 3 次当天禁止翻案。
  - 新手期：首次使用起 7 天内翻的案照常改判（只在本机生效），但样本记入「观察」，
    不进训练池、不上传云端，复核通过也不会转正 —— 前一周还在摸判定口径，错标一条比漏标十条更伤模型。
    7 天后新的翻案恢复正常进训练集；观察样本不会自动转正。
  - 候选 / 回滚的样本不参与训练、不上传云端；设置 → AI 自训练 → 翻案候选池
    可查看审计、驳回、清理回滚记录、清空翻案记录（去毒）。
· 设置 → AI 自训练：
  - 「训练文字模型」：冻结官方语义特征，只重训最后一层（约 1 秒，权重 ~5KB）；
  - 「训练画面校准」：整只 CNN 不能在手机/浏览器重训，这里学的是温度 + 阈值校准，
    用来适配你的光线、坐姿和"什么算摸鱼"的习惯；
  - 两类各至少 10 条样本（正负各 ≥3 条）才能训练；模型可随时在「官方模型 / 我的模型」间切换。
· 云端训练集（默认关闭，需你显式允许）：
  - 勾「允许云端同步训练集」→ 训练集按账号同步到云端，换设备也能拉回来训练；
  - 勾「参与公共训练集」→ 文字样本与画面判定数值（不含摄像头画面）匿名共享，
    也会拉到其他参与者的样本一起训练；介意就别开。
  - 没登录云账号时，训练集只存在本机。

· 限时挑战：周末打卡双倍积分（只加不扣）；新增「铁人三项」徽章（连续 7 天开强制模式 + 保持正分 + 不断打卡）。

【军团 · 和同路人一起撑住】
· 位置：左侧「🏰 军团」页面。服务器就是军团主的电脑 —— 局域网里房主开 TCP 服务，
  跨网络时房主电脑当聚合枢纽，成员用 WebRTC 点对点直连，不经任何第三方。
· 两种通道：
  - 同一个 WiFi：房主把 IP + 军团码发给成员，粘上就加入。
  - 不同网络（异地）：房主生成一段「邀请码」（微信可发），成员粘贴后生成「回执码」
    发回来，房主粘贴即连上。用的是自习房「异地联机」同一套点对点技术。
· 连接方式（设置 → 联机异地设置，二选一；军团异地和自习房/娱乐房的
  「异地联机」共用这一个设置，改完重新配对一次才生效）：
  - 直连优先（默认）：WebRTC 点对点直传，最快、不经任何第三方；严格防火墙下可能连不上。
  - 纯中继：所有流量经 TURN 中继服务器转发，防火墙再严也能连上，多一跳延迟。
    留空用内置公共中继；有自建 coturn 可在设置里填自己的，凭据只存本机。
· 端到端加密：异地通道上所有消息都做 AES-GCM 加密，密钥（256 位）随邀请码由你
  自己发给对方，不经网络 —— 中继或中间人即使看到流量也读不到内容；
  收到未加密或密钥不匹配的数据一律拒收。
· ⚠️ P2P 联机风险与免责：
  - 打洞风险：直连模式靠 NAT 打洞在路由器/防火墙上开出一条通往你电脑的
    直连通道，外部设备有可能借此向你的电脑发送恶意数据包。软件已做两层
    防护（WebRTC 强制 DTLS 加密 + 消息白名单，非本协议的数据包一律丢弃），
    但不能替代杀毒软件和系统防火墙，联机期间建议保持防护开启。
  - 直连模式下双方 IP 互相可见；纯中继模式下对端 IP 藏在 TURN 之后，
    但中继服务器可以看到。
  - 只和信任的人配对：拿到邀请码/连接码的人就能与你建立连接，不要把
    连接码发到群里或公开场合；怀疑泄露就立刻重新配对。
  - 军团为 AES-GCM 端到端加密、房间为 WebRTC 自带 DTLS 加密，但对方设备上的
    数据本软件无法保护，联机时不要泄露敏感信息。
  - 公共 STUN/TURN 由第三方（Google/Cloudflare/openrelay）提供，仅转发加密流量；
    介意者可在设置里填自建 coturn。
  - 免责：使用异地联机/军团功能产生的任何数据泄露、损失或与他人纠纷，
    由使用者自行承担；未成年人请在监护人指导下使用。
· 节奏：不是实时——每隔几小时（默认 4 小时，可改 2/4/8/12）自动上报一次状态；
  关机期间攒下的在下次开机后自动补上。异地连接要求双方软件都开着，关过要重新配对。
· 同步的只有四种状态（都是 0/1）：今日已打卡 / 未打卡 / 强制模式中 / 负分挣扎中。
  计划内容、具体时长、积分余额、契约金额、摄像头画面 —— 一个字段都不在协议里。
· 没加入军团 = 一个包都不发；随时可暂停，退出即停一切外发。
· 军团士气（全团共享，绝不点名）：出操率（零星/过半/全员）、连击达标周数、救援值。
· 你的位置：只显示给你自己 —— 前列/中上/中段/靠后，别人看不到任何名次。
· 集体挑战只奖不罚：本周全团累计打卡达标就发一枚集体徽章，次日打卡积分双倍；
  没凑够就当没发生过，不扣分、不通报。熔断开关可随时关掉自动化奖励。
· 翻车救援：点一盏灯 = 自己掏 5 分（每天最多 3 盏），救援值 +1；正在负分的人每天可
  从救援池领一盏（+5 分）。谁点的、点给谁，系统也不知道。
· 军团日志：只记事件不记人名。
· 换设备接着打（.pqplan 军团段）：导出时的选项里，「军团元数据」与普通计划、
  契约计划并列可选 —— 可选「全部内容 + 军团元数据」一个文件带走，也可以只导出
  「仅军团元数据」的小文件专门搬身份。元数据只含军团码 / 我的代号 / 上报节奏等
  身份字段，不带任何打卡明细。导入后选择「恢复军团身份」，不用重新建团或申请加入：
  局域网直接连接即可，异地连接仍需重新配对一次。注意：带元数据的文件等于你的
  军团身份，只用于自己的备份。

【军团网络 · PK 布告栏 · 频道秩序】
· 军团网络结构重做：房主只跑信令（谁在房里 / 谁跟谁连 / 谁该接管），
  聊天与摘要走成员之间的直连，不过房主。
  - 连接阶梯：STUN 直连 8 秒 → 打不通自动挂 TURN 中继 12 秒 → 仍不通建议装
    Tailscale / ZeroTier 组网（界面上会显示「组网」，数据仍然直传）。
  - 密钥：成员两两 ECDH 现场协商一把 AES-GCM 密钥，房主转发了公钥也解不开；
    30 分钟自动轮换，有人进/出立刻换。
  - 副主选举：房主 45 秒没心跳，按「信誉分高 → 入团早 → uid」选出副主接管信令；
    已建立的直连不断，军团从单点变成可换头。
  - 算账不再依赖房主：每个成员各自用同一份 computeAgg 算聚合，结果自然一致。
· PK 布告栏换成私有 GitHub 仓库（四道防线）：
  1) 单文件写入 + sha 乐观锁：解决「50 个军团最后写的人覆盖前面 49 个」；
  2) Ed25519 签名 + 公钥首次固定：内容被改过验签不过，换钥匙会被单独告警；
  3) 主仓 + 备仓双写双读对比：不一致按主仓为准并记告警；
  4) 每小时快照到 snapshots/<小时>/，保留 48 小时，可回滚。
· Actions 自动校验（每次匹配前）：
  - 出操率 0–100、人数 1–500、专注 ≤1440 分钟、信誉分 ≤160；
  - 越界值回退到「上一次合法值」并写进 logs/<日期>.json；
  - 没有 Actions 也能用：客户端读不到配对表时走本地相邻配对。
  脚本与 workflow 模板在安装目录 tools/github/（pk-actions.js / pk-match.yml）。
· 军团频道秩序（先提醒，再降速，最后禁言）：
  - 10 秒内超过 5 条 / 同一句 30 秒 3 次 → 禁言 3 分钟；
  - 命中脏词 → 禁言 5 分钟；一次 @ 超过 4 人、感叹号过多 → 先提醒；
  - 同一人被禁言 3 次以上 → 单人小黑屋（消息只有他自己看得见）；
  - 信誉分低于 60 → 暂时失去军团发言资格（打卡与助人可挣回）。
· 新手保护罩改成梯度递减（不再是「前 7 天全免、第 8 天全责」）：
  第 1 天只提醒；第 2–3 天扣分减半并提示下次全额；第 4–7 天全额但下限 0；
  第 8 天起正常，可为负并进入负分缓冲。只作用于扣分，加分从不打折。

【军团纪律 · 信誉分 · GitHub 登录】
· 军团页新增「我的纪律状态」：能不能发言、能不能入团、能不能 PK、
  逃兵次数、挂机作废次数、进行中的契约、异常标记，集中在一张卡里。
· 五类违规的判定（全部可解释、可恢复）：
  - 逃兵：专注期失焦累计 ≥90 秒 / 切出 ≥2 次 / 命中干扰进程 ≥2 次
    → 本次扣 3 分（按离开时长最多 3 倍）；信誉分到 -10 冻结军团资格，
    连续打卡 3 天可在卡片上点「解冻」。
  - 刷分狗：按 5 分钟切桶，连续 3 桶（15 分钟）零操作，或前台占比 <50%
    → 本次不计分；第 2 次起每次扣 4 分。只记次数，不记按键内容。
  - 喷子：沿用频道秩序（禁言 → 单人小黑屋）；信誉分 <60 无发言权、
    <40 无 PK 资格。
  - 鸽子精：契约必须有见证人 + 押金（10~100 分，先托管扣走）；
    到期后 12 小时宽限，过了判违约：押金没收 + 扣 6 分。
  - 外挂：单日专注 >1440 分钟、积分跳变 >5000、时间回拨、点击间隔
    恒定 <8ms 等 → 先标记待确认，坐实才清零信誉分并永久封禁军团功能；
    误判点「撤销」不扣分、不留记录。永久封禁只封军团，打卡照常。
· 判定顺序：先判「这一节算不算」，再判「逃不逃」——同一节不会扣两遍。
· 为了让「-10 冻结」真能触发，信誉分下限从 0 放宽到 -30（只用于纪律判定）；
  以前扣到 0 就到底，冻结线永远到不了，等于规则写着不生效。
· 这一批只做逃兵 / 刷分 / 鸽子精 / 外挂四类。负分缓冲本来就有，不重做：
  借分、救赎券、负分分级（轻 / 中 / 重三档）继续照旧工作，
  这次只是让它和「信誉分 -10 冻结军团资格」对上。
· 信誉分不可购买：只有「被证实的翻案 / 被核实的举报 / 按约还清借款 /
  纪律记录」四类来源，商城与兑换没有任何入口能动它。

  git credential → 设置里存的 顺序查找；设置页显示来源与掩码

  跑一次 gh auth login。

【AI 训练和翻案是什么关系（一条样本的完整一生）】
· 一句话：翻案是训练集「唯一的人工入口」，信誉分是这个入口的闸门。
  翻案负责改，风控负责能不能改，训练负责改完怎么用。三者是一条链，不是三个功能。
· 五步链路：
  ① 判错：模型给出标签 → 本机样本池（未标注）
  ② 翻案：双击徽章（手机长按 / 右键）→ 必选理由 → 二次确认 → 写审计日志
  ③ 裁决：direct 立即改判 / pending 挂「⏳ 待确认」进候选池 / 房间公投转正 / 10 分钟内被
     3 条闲聊打脸则回滚
  ④ 训练：只吃 direct 和 confirmed；每类 10 条可训，40 条起留 20% 做验证集
  ⑤ 上传（可选）：候选池、被回滚、被本机拦下的样本一条都不传
· 信誉分在链上出现三次：
  - 卡次数：受限 <80 每天 2 次、普通 5 次、良好 10 次、可信 ≥120 20 次；
    间隔 15 秒，同一条 24 小时只准翻一次。
  - 卡权重：可信 1.0 / 良好 0.8 / 普通 0.5 / 受限 0.2；
    只有「良好」及以上才可能 direct 直接进训练集，其余先在候选池等人复核。
  - 卡资格：分数到 0 进 24 小时失信期，翻案与借分一起锁死；历史准确率低于 50% 自动降一档；
    新号首日最高「普通」、三日内最高「良好」。
· 反向回路：模型学走你的习惯 → 误判变少 → 翻案变少；翻案不实 → 回滚并扣分 → 权重更低 →
  更难直接生效；训练后留出验证准确率低于 0.6 → 提示先清候选池；每类保留最近 8 个模型可回退。
· 三个误解：
  - 多翻案不能刷分：被证实 +3（每天最多 6），被推翻 -8，恶意翻案亏得更多。
  - 翻错不会学坏：训练和上传两处都按状态过滤，单条脏样本进不了权重。
  - 翻案理由别人看不到：只留在本机；进公投的只有「🛡 翻案待复核 #编号」。

【军团治理：人员目录 · 信誉等级 · 投票选职务】
· 军团页新增「团内治理」：团内成员目录（昵称 + 信誉等级 + 职务 + 在线状态）。
  只显示等级徽章（受限 / 普通 / 良好 / 可信；普通及以上并排标 L1/L2/L3，受限没有等级），
  不显示具体分数；
  信誉 ≥120 的人名旁挂 ✦ 守约者星标。
· 「我在团里的信誉位置」：治理面板顶部有一张自己的卡 —— 第 X / N 位、高于团里
  百分之多少的人、自己的等级徽章。只给自己的名次，不显示别人的分数。
· 裁定类职务（纪律官 / 仲裁员）提案时，信誉低于 100 分的人会被挡下（L2 社交特权）。
· 三类投票：
  - 发言审核：某条发言算摸鱼还是正经事，投票通过才改判，并修正训练样本。
  - 选职务：团长按信誉等级提名候选人，发起投票，通过后自动任命。
  - 其他事项：任何「普通」及以上成员都能发起（改集合时间、换 PK 项目等）。
· 投票规则：
  - 有效期 10 分钟，期间可改票，只留最后一次。
  - 法定人数：在线成员过半参与且至少 2 人，否则即使全票同意也判「未通过」。
  - 通过条件：同意率 ≥60% 且同意多于反对。
  - 自己不能投自己的投票，也不能举报自己发的投票。
· 发起成本（防刷）：
  - 需要「普通」及以上；每日 2 / 3 / 4 次（普通 / 良好 / 可信）。
  - 同时最多 2 个未结束的投票。
  - 团里不到 4 人时，团长可以直接任命职务（凑不够法定人数），但会记进审计。
· 举报乱发：3 个不同的人举报 → 投票作废 + 发起人禁发起 24 小时 + 扣 3 分（每天最多 6 分）。
· 四种职务与权限（只给权限，不给分数，也不能改别人的分）：
  - 副团长：发起投票、禁言、提议任命
  - 纪律官：发起投票、禁言、裁定争议投票
  - 仲裁员：裁定争议投票、审核发言是否摸鱼
  - 记录官：查看审计记录
· 手机版：只能查看，不提供发起/投票入口（避免「手机投了、电脑没算」的分叉）。
· 版本号 2.7.0；网页缓存升到 pq-web-v37。

【军团频道：自己的频道 · 团长定的规则 · 转发】
· 在哪：军团页「团内治理」下面就是「军团频道」。不进自习房也能说话。
· 和房间的关系：底层是同一套——同一个 WiFi 走 TCP，异地走 WebRTC 直连。
  所以房间能转发的东西，频道也能；频道发的链接，房间里也能点开。
· 团长可调的四样（只有军团主能改，成员只读）：
  - 开关：关掉后频道只读，历史还在，谁也不能发。
  - 严格度：宽松 / 标准 / 严格，决定刷屏与复读的阈值，也决定发言需要的信誉分
    （宽松 ≥40 / 标准 ≥60 / 严格 ≥80）。
  - 禁言时长：跟随档位，或 3 / 5 / 10 / 20 / 30 分钟。
  - 自定义词：每行一个或用逗号隔开，最多 20 个（每个 2–8 字）；内置词表一直在。
  改完立刻生效，成员那边自动跟上，频道顶部一直写着当前规则。
· 什么会被拦：辱骂、刷屏（时间窗条数超阈值）、复读（同一句重复超阈值）→ 禁言；
  一次 @ 太多人、感叹号/大写太多 → 只提醒不罚。
  禁言不进信誉分账本；团长可以手动禁言 / 解禁，被禁言的人本地立刻发不出去。
· @ 人：输入 @ 列出团里的人，点一下补全；被 @ 的消息高亮，标题上有未读数，
  点一下消息区就算已读。系统不会回「已读」回执，别人不知道你看没看。
· 转发（点输入框左边的 📎）：
  - 我的全部计划 / 普通计划 / 契约计划：把整份 .pqplan 作为附件发出去。
    发送前会再确认一次——计划里的备注会一起发出去。对方点「合并导入」，
    只合并、不覆盖他本机数据；超过 60KB 会提示改用「导出」生成文件。
  - 我的房间链接：pq://room?ip=…&port=…&code=…，对方点「进入房间」即可；
    正在开房的房主也可以直接点「邀进房间」。
  - 我的军团链接：pq://legion?…（局域网直接加入；异地自带邀请码，
    对方点开生成回执码，发回团长即可）。已经在军团里的人会被提醒先退出。
· 链接是纯文本，贴到微信也能被人打开（认得的客户端渲染成按钮，不认得的只是一行字）。
· 手机版：可以看频道与规则；发消息、改规则、转发仍以电脑版为准。
· 版本号 2.8.0；网页缓存升到 pq-web-v38。

· 谁都不能直接任命职务了——团长也不行（小团不到 4 人的「直接任命」入口已取消）。
  任命一律发起「选职务」投票，大家表决。
· 职务投票只有团长和副团长能发起（副团长靠「提议任命职务」权限）；其他成员不能发起。
  因为乱发投票被禁发起的人，同样不能发起职务投票。
· 一人一职：每人同时最多一个职务。已经有职务的人不会出现在候选人里，
  想换职务得先投票撤销旧的。投票通过时如果候选人已经领了别的职务，结果落空并记进台账。
· 撤销职务仍只有团长能做（撤销不是任命，是为了腾出一人一职的名额）。

【建团即团长】
· 创建军团的那一刻就自动成为军团长（局域网 / 异地枢纽 / 网格三种开团方式都一样）。
· 重新建团会立刻接管团长身份：旧团的职务、投票、举报、禁发起记录全部清空，不会带进新团。
· 加入别人的军团不会动这个判定——团长身份只认「谁建的团」。

【团长退团：公告 + 选举接任】
· 团长退出军团时，频道先发公告。
· 异地（网格）军团：公告后自动开启 10 分钟团长选举——治理面板顶部出现「团长选举」卡片，
  任何「普通」及以上成员都能点「参选团长」；每人一票，改票只留最后一次，只能投给已参选的人。
· 到点自动结算（不用有人开着面板）：参与人数要过半且至少 2 人；票多者接任团长，
  平票先比信誉等级、再按 uid 排序——每台电脑算出的新团长是同一个。
· 选举没成（人数不足或没人参选）：团里暂时没有团长，任何普通以上成员可以点「重新发起选举」。
· 局域网军团依附团长的电脑：团长退团即解散，公告会提示大家可以用 pq://legion 链接重新组团。
· 退出军团会清空本机的治理台账（职务、投票、选举记录），不会带到下一个团。

【好友区（新页面「🤝 好友」）】
· F0 未结缘：不能搜陌生人私信。结缘只走三条正路——双人自习室同房打卡、
  对赌契约互为监督、问答申请（对方出 1~5 题并自带答案键，全对才放行）。
· F1 搭子档（默认）：纯文本 + 软件内链接（计划 / 房间 / 军团）；
  消息 24 小时焚毁；每日 20 条；双方今日完成率都要 ≥50% 才能发——
  两边都摆烂时输入框直接灰掉，提示「先各自干活」。禁图片 / 文件 / 外部链接。
· F2 战友档：双方当日都 100% 全勤 → 次日自动升级；任一方断勤退回 F1；
  连续 3 天断勤自动解缘回 F0。F2 每日 50 条，可发打卡截图互证与计划包（仍要二次确认）。
· 任务排行：好友页排行榜按今日完成率排（我 + 所有搭子），前三名金银铜牌，平分按昵称序。
· 互相契约：和搭子立对赌——双方各押 5~200 分、约 3~30 天，断勤一天扣「押金÷天数」向上取整，
  全勤到期全退；生效中不能重复立，可提前结算（漏的天照样扣）。
· 自动提醒对方：每晚 21 点后你还有没打完的卡，软件自动给每个搭子发一条免费提醒
  （不占每日额度，每天每人最多一条；21 点前和任务清零后都不会发）。
· 好友页的「结算昨日全勤」按钮：手动触发 F1→F2 升降判定；到点也会自动结算。

【军团闲聊档位 L0~L3 与集体任务】
· L0 静默（默认）：个人完成率 <50% 或集体任务未达基线——频道只读，
  只能发打卡截图 / 系统通知 / 求助@团长 / 非闲聊文本 / 软件内链接；
  闲聊被 AI 雷达折叠并提示「先干活」，不扣分。
· L1 轻聊：个人今日完成率 ≥50% 解锁——纯文本 ≤50 字/条 + 软件内链接；
  闲聊超 3 条/小时自动回落 L0 到次日重置。
· L2 狂欢：军团集体任务达成解锁——长文 / 图片 / 语音房 / 表情包全开，窗口到当日 24 点；
  个人贡献 <30% 的成员不跟随解锁（防搭便车），只回 L1。
· L3 荣光：个人连续 7 天全勤且军团本周集体任务全勤——自定义头衔 / 置顶庆功公告 /
  专属徽章展示，纯荣誉层。
· 集体任务：团长发起（名称 + 基线 60~100%），成员在治理面板汇报贡献；
  达成后全团 +20 分、记为当日完成的一个任务，并直接解锁 L2。

【.pqplan 安全四件套】
· 计划预览（二次确认）：收到计划包先弹预览窗——全部项目、契约、积分规则、押金列清楚，
  手动点「确认导入」才生效。
· 来源标记：计划包自动带发送者 ID 与时间戳，导入后出问题能追溯到源头、能举报。
· 24 小时沙箱：确认导入后先进沙箱——积分变动和契约执行都是虚拟的，不碰主计划；
  治理面板出现「沙箱里的计划包」卡片，24h 内没问题点「转正」，有问题点「删除」。
· 军团计划黑名单：团长在成员目录点「拉黑计划」，此后 TA 发的任何 .pqplan 被自动拦截，
  接收方连预览都看不到。

【分级管理权 Lv1~Lv3】
· Lv1 劝导权（团长默认）：对成员的聊天「折叠 + 私信提醒」，不公开处刑；
  被提醒 3 次进观察名单，团长可看其发言频率统计。不能禁言、不能踢人。
· Lv2 管制权：团长对成员发起禁言 1/6/24 小时或移出话题（不踢军团）——必须填理由，
  理由记入全员可查的军团日志；须副团长投票过半才生效；
  管制被 3 人举报作废算滥用，累积 3 次滥用自动解除团长职务。
· Lv3 驱逐权：驱逐提案 24 小时全员投票，赞成超过 2/3 才执行；
  被驱逐者有 7 天申诉期，申诉成功恢复成员身份，发起驱逐的团长扣 50 信誉。
· 被驱逐时：治理面板顶部出现驱逐横幅，申诉期内可填证据提交申诉（判定是确定性的）。

【阿刺补刀与代填代回】
· 主动加油：任务连续几轮没动时，阿刺浮标亮起，点开第一句就是加油（一天最多 3 次，
  进度一动就不再念）。
· 「帮我填」：自动填昵称 / 姓名 / 名字 / 监督人这类表单框（值取本机资料，
  不猜邮箱手机号）。
· 「帮我回」：按当前完成率代拟三条回复，挑一条贴过去就能过闲聊雷达。
