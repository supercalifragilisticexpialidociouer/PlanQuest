⚖️ 顶罪最终算法 每次扣分事件触发

概率 = 25% + 心情 × 5%（钳在 10% ~ 70%）
心情 9 → 70% ｜ 3 → 40% ｜ −3 → 10%
R = 随机数(0~100)；R < 概率×100 → 顶罪
  1. 检查全局冷却（30 分钟）+ 每日上限（1 次）
  2. 获取阿刺当前心情 → 计算概率修正
  3. 生成随机数 R（0~100）
  4. R < 基础 25% + 心情修正 → 顶罪
  5. 顶罪后：积分实扣 0，协作能量 −50、好感 −3、重置冷却
  6. 无论顶不顶，台词都按当前心情档变化（好 / 一般 / 差三套）
周最多 3 次、月最多 10 次；能量不足 50 不顶；超限台词「你以为我是你爹啊？自己拉的屎自己擦。」
硬约束：不导出 forceCover / requestCover / setProbability，聊天里求他扛只会被怼回来 —— 不可以规定他是否顶罪。
