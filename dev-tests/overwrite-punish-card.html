0需求基线：计分口径

打开编辑不算数，只有真正「应用」才计分。

新增计划 → 按普通新建口径 plan:save：新增非白名单普通软件扣 10 分／计划，契约任务 0 分
覆盖掉的计划 → 按删除口径 plan:delete：0 分（常量对齐，规则变了自动跟随）
合并导入 → 只算新增，不删本机计划，不升级阶梯
只打开编辑（.pqplan） → inspect：不扣分、不应用、不记账、不进审讯，可改可另存

1扣积分太轻了，得「扣刺」

一次性动四处：积分、协作能量、经验、等级。

积分：按当前积分扣 10% / 30% / 50%（向上取整，无分可扣时为 0）
协作能量：aci.energy −2 / −3 / −5
经验：aci.exp −80 / −160 / −300
降级：第 3 档起 Lv./100 直接掉回 Lv.1 新手、经验清零、心情转 angry
每次开口：斜眼笑 / 翻白眼 / 生气脸，表情负责娇，文案负责傲

2「无损」变「有损」，历史留痕

旧计划不真删，加密藏个备份，下次启动当面翻旧账。

桌面：aes-256-gcm 密文写 overwrite-vault.json，密钥独立存 overwrite-vault.key
网页 / 安卓：Web Crypto AES-GCM，密钥与密文分键存 localStorage
data.json 只留索引（时间／条数／标题／sha256），看不到旧计划明文；导出文件不带账本
翻旧账：「哟，这文件看着眼生啊……逃兵行为，扣 10 积分、80 经验。本刺替你记着呢，别想装失忆。」读一次即销账
全量覆盖会把 data 整个换掉，账本会挂回本机状态 —— 别想拿文件抹掉逃兵记录
