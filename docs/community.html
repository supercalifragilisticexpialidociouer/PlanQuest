刺窝 · 生人勿近，熟人扎心

这里不是那种“大家互相鼓励加油哦”的温柔乡。这是 PlanQuest 用户的聚集地，一群被阿刺虐、还坚持打卡的硬核玩家。你可以吐槽、可以求饶、可以晒连击，但别指望谁会温柔哄你——毕竟连阿刺都不惯着你，我们更不会。

进入刺窝 去 Issues 吼一声（Bug 反馈） 查看 GitHub Issues

发帖 / 评论需 GitHub 登录（giscus 自带），天然过滤灌水党。管理在 GitHub 网页端删帖、锁帖、打 label。

四个区，各扎各的

板块数据托管在 GitHub Discussions；当前复用仓库默认分类，可在 GitHub 网页端 Settings → Discussions 里改成中文名，giscus 容器 id 不变。

01挨扎日记（General）

  • 晒你今天被阿刺骂了啥（“豪猪今天又冷眼旁观我摆烂，气死”）
  • 分享打卡连击，但别太得瑟，容易被其他刺友围攻
  • 发帖前提醒：阿刺看着呢，别立 Flag 第二天就断

02驯刺补遗（Show and tell）

  • 五种皮肤实测：仙人掌到底比玫瑰嘴硬多少？刺猬养熟要几天？
  • 文件同步骚操作：怎么让网页版 / 安卓 / Win 无缝切换还不丢连击
  • 坑位预警：新建空白文件覆盖原计划的血泪史（欢迎投稿）

03阿刺发疯 / 背锅现场（Q&A）

04刺窝公告（Announcements）

  • 版本更新：新皮肤？新惩罚机制？阿刺又变毒了？
  • 社区规则：禁止卖惨、禁止无意义灌水、禁止求阿刺心软（求也没用）
  • 开源相关：GitHub 链接、贡献指南（想改阿刺脾气？提 PR 吧）

置顶规则（刻薄版）

  1. 不卖惨。打卡断了就断，别写小作文哭诉，阿刺不心疼，刺友更不。
  2. 不灌水。发“打卡第 1 天”可以，发“啊啊啊”直接沉。
  3. 不求饶。求阿刺心软、求别人鼓励，一律当笑话处理。
  4. 真反馈。Bug 请带截图 + 系统版本，骂街不带细节的忽略。
  5. 晒连击可以，但别炫耀过头——豪猪派会来扎你。
